# C++ Loops and Comparison Operators Practice

This repository contains my C++ basic practice codes focused on strengthening logic building, mastering loops, and using comparison operators.

## 🚀 Programs Included:
1. **Multiplication Table**: A program to print tables for any user-input number.
2. **Countdown Timer**: A reverse loop program counting down to 1.
3. **Sum of N Numbers**: Logic to calculate the sum of numbers from 1 to N.
4. **Even Numbers Printer**: Program to print all even numbers between 1 and 20.
